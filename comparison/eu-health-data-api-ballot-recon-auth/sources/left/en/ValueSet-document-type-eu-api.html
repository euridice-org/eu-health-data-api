Document type codes for clinical precision in document identification.

References

This value set is not used here; it may be used elsewhere (e.g. specifications and/or implementations that use this content)

Logical Definition (CLD)

This value set includes codes based on the following rules:

  • Import all the codes that are contained in EEHRxF Document Type ValueSet for Patient Summaries
  • Import all the codes that are contained in EEHRxF Document Type ValueSet for Discharge Reports
  • Import all the codes that are contained in EEHRxF Document Type ValueSet for Laboratory Reports
  • Import all the codes that are contained in EEHRxF Document Type ValueSet for Medical Imaging
